# Enterprise Task Manager

Кроссплатформенная система управления рабочими задачами, заявками и распределением ресурсов, разработанная на стеке .NET MAUI Blazor Hybrid и PostgreSQL. Проект спроектирован с учетом требований к корпоративной безопасности данных, разграничению прав доступа и отказоустойчивости клиент-серверного взаимодействия.

## Основное назначение

Приложение решает задачу централизованного контроля поручений, диспетчеризации инцидентов и отслеживания статусов выполнения работ в распределенных командах. Использование гибридной архитектуры (.NET MAUI + Blazor) обеспечивает единую кодовую базу для настольных и мобильных платформ при сохранении нативной производительности.

## Ключевые архитектурные и функциональные особенности

* **Ролевая модель доступа (RBAC):** Разграничение функциональности и видимости интерфейса в зависимости от роли пользователя (администратор, диспетчер, исполнитель).
* **Безопасность на уровне базы данных (Row-Level Security):** Изоляция данных реализована не только на уровне клиентской логики, но и непосредственно в PostgreSQL через политики RLS, что исключает несанкционированный доступ к записям при прямых запросах к API.
* **Слоистая архитектура и паттерн Repository:** Четкое разделение бизнес-логики, слоя доступа к данным (Data Access Layer) и пользовательского интерфейса. Использование внедрения зависимостей (Dependency Injection) упрощает модульное тестирование и поддержку кода.
* **Реактивный интерфейс:** Компонентный подход на базе Razor-компонентов и строгой привязки данных обеспечивает мгновенное обновление таблиц, статусов заявок и аналитических сводок без полной перезагрузки представлений.
* **Нормализованная схема БД:** Поддержка связей между задачами, рабочими зонами, ответственными исполнителями и историей изменений статусов (аудит-лог).

## Технологический стек

* **Платформа и язык:** C#, .NET (MAUI / Blazor Hybrid)
* **Пользовательский интерфейс:** Razor Components, HTML5, CSS3, адаптивная верстка
* **База данных и бэкенд-сервисы:** PostgreSQL, Supabase (REST API, Auth, Row-Level Security)
* **Архитектурные паттерны:** Repository Pattern, Dependency Injection, MVVM / Component-based UI
* **Инструменты контроля версий и сборки:** Git, MSBuild / .NET CLI

## Сборка и запуск

### Предварительные требования
* Установленный .NET SDK (с рабочей нагрузкой `.NET MAUI`)
* Экземпляр базы данных PostgreSQL (локальный или облачный через Supabase)
* Среда разработки Visual Studio 2022+ или JetBrains Rider

### Инструкция по развертыванию

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/DeAdmin01/task-manager.git
   cd task-manager
   ```

2. Настройте подключение к базе данных:
   Создайте конфигурационный файл или укажите параметры подключения (URL и API-ключ / строку подключения PostgreSQL) в настройках окружения проекта.

3. Примените схему базы данных:
   Выполните SQL-скрипты инициализации таблиц и политик безопасности (RLS) на вашем сервере PostgreSQL.

4. Восстановите зависимости и соберите проект:
   ```bash
   dotnet restore
   dotnet build -c Release
   ```

5. Запустите приложение для целевой платформы (например, Windows или Android):
   ```bash
   dotnet build -t:Run -f net9.0-windows10.0.19041.0
   ```
